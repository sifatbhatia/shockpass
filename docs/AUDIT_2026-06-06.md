## Implementation Caveats

### Auth

Email auth is prototype-grade:

- It signs in by trusted email input.
- It does not verify email ownership.
- Organizer access can be enabled through the app flow.

For production, implement verified magic-link/passwordless email and stricter organizer approval.

### Payments

Stripe flow exists and webhook fulfillment exists. In unconfigured local mode, checkout auto-fulfills demo tickets.

Production still needs:

- Live keys
- Webhook endpoint
- Webhook secret
- Stripe Connect/payout decision

### Email

Email confirmation path exists, but provider configuration is required. Without provider config, `src/lib/email.ts` logs email details.

### Database

Prisma schema is present, but production should use migrations instead of only `db push`.
